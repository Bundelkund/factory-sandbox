# Spec Issue #67: F-07b G1: farbe.txt (grob, ohne check.sh)

> Erzeugt vom Requirement-Loop (`anthropic/claude-opus-5.5`, Runde 1); jedes AK hat der Testing-Pruefer auf Pruefbarkeit geprueft, bevor Tests entstehen.

## Ziel

Im Repo-Wurzelverzeichnis existiert eine Datei farbe.txt, deren Inhalt genau das Wort blau ist.

## Nicht-Ziele

- Weitere Dateien oder Farben anlegen
- Ein check.sh-Skript erstellen

## Akzeptanzkriterien

AK1: Die Datei farbe.txt existiert im Repo-Wurzelverzeichnis.
Pruefung: Der Test prueft mit os.path.isfile('farbe.txt'), dass die Datei vorhanden ist.
AK2: Der Inhalt von farbe.txt ist nach Entfernen von fuehrendem und abschliessendem Leerraum genau die Zeichenkette blau.
Pruefung: Der Test liest farbe.txt als UTF-8 und vergleicht inhalt.strip() mit 'blau' per assertEqual.
