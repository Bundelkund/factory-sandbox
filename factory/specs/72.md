# Spec Issue #72: Datei eins.txt anlegen

> AK von Hand aus dem Issue (kein check.sh im Issue): der Testing-Pruefer nimmt jedes AK ab, bevor Tests entstehen.

## Ziel

Datei eins.txt anlegen

## Akzeptanzkriterien

AK1: Die Datei eins.txt existiert im Repository-Wurzelverzeichnis.
Pruefung: self.assertTrue(os.path.isfile('eins.txt'))
AK2: Der Inhalt von eins.txt ist nach Entfernen von umgebendem Leerraum genau das Wort eins.
Pruefung: self.assertEqual(open('eins.txt', encoding='utf-8').read().strip(), 'eins')
