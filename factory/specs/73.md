# Spec Issue #73: Datei zwei.txt anlegen

> AK von Hand aus dem Issue (kein check.sh im Issue): der Testing-Pruefer nimmt jedes AK ab, bevor Tests entstehen.

## Ziel

Datei zwei.txt anlegen

## Akzeptanzkriterien

AK1: Die Datei zwei.txt existiert im Repository-Wurzelverzeichnis.
Pruefung: self.assertTrue(os.path.isfile('zwei.txt'))
AK2: Der Inhalt von zwei.txt ist nach Entfernen von umgebendem Leerraum genau das Wort zwei.
Pruefung: self.assertEqual(open('zwei.txt', encoding='utf-8').read().strip(), 'zwei')
