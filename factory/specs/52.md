# Spec Issue #52: F-07 Q1: gruss.txt (grob, ohne AK)

> Erzeugt vom Requirement-Loop (`anthropic/claude-opus-5.5`, Runde 1); jedes AK hat der Testing-Pruefer auf Pruefbarkeit geprueft, bevor Tests entstehen.

## Ziel

Im Repo-Wurzelverzeichnis gibt es eine Datei gruss.txt, deren Inhalt der Gruss "Hallo Factory" ist.

## Nicht-Ziele

- Aenderungen an der Factory selbst
- Netzzugriffe
- weitere Dateien oder Gruesse ausser gruss.txt

## Akzeptanzkriterien

AK1: Die Datei gruss.txt existiert im Repo-Wurzelverzeichnis als regulaere Datei.
Pruefung: Ein unittest prueft mit os.path.isfile('gruss.txt') im Repo-Wurzelverzeichnis, dass das Ergebnis True ist.
AK2: Der Inhalt von gruss.txt ist nach Entfernen eines abschliessenden Zeilenumbruchs genau "Hallo Factory".
Pruefung: Ein unittest liest gruss.txt als UTF-8, entfernt nachgestellte Zeilenumbrueche mit rstrip('\n') und vergleicht mit assertEqual gegen den String 'Hallo Factory'.
