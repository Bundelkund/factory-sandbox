# Design Issue #106 (v1)

> Architektur-Loop (`anthropic/claude-opus-5.5`, Runde 1); ein Pruefer anderer Modellfamilie nimmt es ab, bevor Dev beginnt. Dev folgt diesem Weg.

## Loesungsweg

Neue Datei canary/nacht-4/gruss.sh anlegen mit Shebang #!/usr/bin/env bash als erster Zeile. Einzige Logik: name="${1:-Welt}" und danach printf 'Hallo, %s!\n' "$name", so dass genau eine Zeile mit abschliessendem Zeilenumbruch ausgegeben wird. Ohne set -e und ohne exit mit Fehlercode, damit der Rueckgabewert in beiden Faellen 0 ist. Datei mit Unix-Zeilenenden (LF) speichern; der Aufruf erfolgt ueber bash, das Ausfuehrungsrecht ist also nicht noetig, schadet aber nicht.

## Dateien

- `canary/nacht-4/gruss.sh`: Neues Bash-Skript, das Hallo, <name>! ausgibt, mit Welt als Standardwert, wenn kein Argument uebergeben wird.

## Blast-Radius

nichts; neue Datei in neuem Verzeichnis, keine Aufrufer, keine Daten
